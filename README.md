# Gen Z und Politik

Interaktive Informationswebsite zu den Gen-Z-Protesten für den Politikunterricht.

## Projektziel

Die Schülerinnen und Schüler erkunden die öffentlich erreichbare Informationswebsite 30–40 Minuten selbstständig auf Handy oder iPad. Anschließend führt ein Link zu einem Mentimeter-Exit-Ticket mit Wissensfragen und persönlichen Einschätzungen. Antworten werden ausschließlich in Mentimeter zentral gesammelt und gemeinsam ausgewertet.

Die Veröffentlichung über GitHub Pages wird zusammen mit der Website eingerichtet.
